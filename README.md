# 火柴人战争 · 余烬王国

一款完整可玩的中文浏览器即时战略游戏，以火柴人战争的采矿、训练和雕像攻防玩法为灵感，采用原创 Canvas 场景、角色和战役设计。非官方作品，不包含原作素材、音频或代码。

## 本地运行

需要 Python 3；无需安装前端依赖。

```sh
npm start
# 或者
python -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。静态文件均位于 `dist/`，可直接部署到支持静态文件的 HTTPS 服务。

## 已实现

- 六种兵种：矿工、剑士、弓箭手、长矛卫士、巫师、巨人。
- 采矿、运金、训练队列、取消退款和 40 人口上限。
- 近战、飞行箭矢、范围魔法、巨人攻城、生命与死亡动画。
- 驻守回血、防守集结、全军进攻和敌军训练／进攻 AI。
- 直接控制我方单位，手动攻击获得伤害加成。
- 军团狂怒与全军治疗，独立冷却计时。
- 六章渐进战役、通关评分、下一关解锁和水晶奖励。
- 无尽防线模式、渐强波次和个人最佳纪录。
- 水晶兵工厂永久升级、兵种图鉴和游戏内操作手册。
- 休闲／标准／困难难度，1×／2×／3×速度，暂停与全屏。
- 合成战斗音效、减少动画选项、手机触摸操作和响应式布局。
- 浏览器本地自动存档，每 5 秒保存；刷新后可继续当前战斗。
- 场景、图标、音效与字体均本地提供，运行时无需请求外部服务。

## 操作

| 操作 | 键位 |
| --- | --- |
| 训练六种兵种 | 1–6 |
| 驻守／防守／进攻 | Z / X / C |
| 狂怒／治疗 | Q / E |
| 暂停 | P |
| 移动战场视野 | 方向键、拖动战场、滚轮或点击小地图 |
| 选择单位 | 点击我方单位 |
| 控制单位移动／攻击 | A、D / 空格 |
| 解除控制／关闭窗口 | Esc |

触摸设备在选中单位后显示方向与攻击按钮。兵工厂升级和难度修改在下一场战斗生效。

## 验证

需要 Node.js 20 或更高版本：

```sh
npm run check
npm test
```

12 项确定性测试覆盖经济、训练退款、人口限制、暂停、技能、远程与范围伤害、驻守恢复、可达成的胜利、失败、全部兵种、存档恢复与无尽模式。

另已通过 Chromium 桌面（1440px）与移动端（390px）浏览器交互检查。存档仅保存在当前浏览器；清除网站数据会清除进度。此版本为单人游戏，无账号同步或联网对战。

## 文件

- `dist/engine.js`：可独立测试的战斗模拟。
- `dist/art.js`：Canvas 战场、单位动画和 SVG 图标。
- `dist/game.js`：界面、输入、音效、存档及战役系统。
- `dist/style.css`：响应式界面样式。
- `tests/engine.test.mjs`：核心逻辑测试。

字体使用 Noto CJK 的本地子集，许可证见 `dist/assets/fonts/LICENSE.txt`。
