# 火柴人战争 · 余烬王国 0.2.0

中文单人浏览器策略游戏：采矿、训练六种火柴人兵种、装备皮肤、使用补给，在 30 个关卡中指挥雕像攻防与护送。附带面向二年级孩子和家长的完整游戏制作工坊。

这是围绕《火柴人战争：遗产》核心玩法制作的非官方网页重制，角色、界面、场景、关卡脚本与音效由本项目独立实现，不包含原作素材、代码或音频，也不声称与原作逐像素、逐关卡一致。

## 直接运行游戏

需要 Python 3，无前端依赖、无需构建。终端进入此目录：

```sh
python -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。安装 Node.js 时也可以使用 `npm start`。正式游戏使用 ES 模块，请通过 HTTP 服务运行，不要双击正式版 `dist/index.html`。`dist/learn/examples/` 内的教学小作品都是独立 HTML，可直接双击、离线运行。

## 任务与装备规则

- 攻城：先摧毁敌方雕像。限时攻城：还需在倒计时结束前完成。
- 防守：自己的雕像存活到指定时间。敌方雕像不可作为通关条件。
- 护送：矿车抵达右侧终点；前方没有护卫或附近有敌军时等待。矿车或我方雕像被摧毁均判负。
- 永久升级和难度在下一场生效。准备阶段换装立即生效，已经开战时换装从下一场生效。
- 皮肤解锁一次即可为全部兵种分别装备；购买不重复扣款。道具条件不满足时不扣库存。
- 旧六章进度迁移为对应章节终点星级，水晶和升级保留；旧战斗结构不兼容，回到营地重新开始。迁移前自动留一份浏览器本地备份。

## 操作

| 操作 | 键位 / 方式 |
| --- | --- |
| 训练六兵种 | 1–6 或点击卡片 |
| 驻守 / 防守 / 进攻 | Z / X / C |
| 狂怒 / 治疗 | Q / E |
| 暂停 | P |
| 移动战场视野 | 方向键、拖动、滚轮或点击小地图 |
| 选择单位 | 点击我方单位 |
| 控制单位移动 / 攻击 | A、D / 空格 |
| 解除控制 / 关闭窗口 | Esc |

手机选中单位后显示方向和攻击按钮。战术道具在战场下方使用。

## 带孩子开始

第一天只做第一课：拿四颗豆子、一张矿工卡和一张守卫卡，一起讨论“先开采，再买谁”。孩子负责预测、画角色、改数字和解释发现；家长负责打字协助、保存、账号与发布。

打开工坊选择第 2 课，找到 `gold=gold+1`，把 1 改成 2，再点击运行。之后按课程逐步连接判断、动画、状态机、队列和战斗。下载「我的作品」即可保存修改后的独立 HTML。教程也提供从空白文件输入 9 行代码的步骤。

教学最终作品是精简的三关游戏；正式版源码作为后续拓展。不要让孩子第一天阅读整个战斗引擎。

## 验证

规则测试需要 Node.js 20+，不需要安装 npm 依赖：

```sh
npm run check
npm test
```

0.2.0 包含 62 项通过的测试（含 30 个连续战役子测试），覆盖经济、训练、人口、战斗、目标结算、皮肤、六种道具、存档迁移和长期进度。完整战役测试使用正常采矿所得黄金，所有升级、皮肤、补给均由同一份真实通关奖励支付；没有给模拟器注入无限资源。它验证标准难度的可达性，不等于每一种阵容或每一次操作都能通关。

浏览器检查需要 Playwright 与 Chromium，先启动本地 HTTP 服务：

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

可使用 `BASE_URL`、`PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`QA_ARTIFACTS` 指定运行环境。检查桌面、390px 触屏、换装兑换、库存消耗、队列、四类结算、全屏弹窗、存档、六种环境、工坊编辑、下载、日记和 12 个示例。截图输出到被 Git 忽略的 `artifacts/`。

| `dist/classic.css`、`dist/style.css` | 游戏界面及响应式布局 |

| `docs/` | 教程、设计说明、测试与发布记录 |
| `scripts/build-learning.py` | 生成 12 个独立教学 HTML |
| `scripts/build-workshop.py` | 从 Markdown 生成工坊阅读页面 |
| `scripts/build-pdf.mjs` | 生成教程与打印卡 PDF |
| `tests/` | 规则测试与连续战役验证 |

编辑教程源文件后，使用 Python 3 与 Markdown 库生成页面：`python -m pip install Markdown`，然后运行 `python scripts/build-learning.py` 和 `python scripts/build-workshop.py`。本地服务器启动后运行 `node scripts/build-pdf.mjs`，最后 `python scripts/package-learning.py` 生成材料包。字体子集可用 `scripts/subset-fonts.py` 重建，需要 FontTools 和本地 Noto CJK。

字体使用 Noto CJK 本地子集，许可证见 `dist/assets/fonts/LICENSE.txt`。课程与游戏原创绘制部分归本项目；第三方名称仅用于说明玩法来源。
