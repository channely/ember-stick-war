# 0.3.0 规则对齐与网页标定记录

核对日期：2026-11-06。目标作品为 **Stick War: Legacy（火柴人战争：遗产）** 的经典战役与核心系统，不使用 Stick War: Saga、Stick War II 或修改版的参数补空。

## 怎样阅读这张表

- **官方确认**：开发者商店说明直接支持这一玩法能力。
- **社区 Legacy 参考**：资料的 Legacy / SWL 专节支持，属于社区整理，不代表官方精确数值保证。
- **网页标定**：为本项目的浏览器输入、节奏、教学或兼容性明确选择的规则。测试应核对实现与说明一致，不把它写成原作事实。
- **待实机校准**：公开资料缺失或互相矛盾。参数在 `dist/rules.js`、`dist/content.js` 与 `dist/sim/` 中公开，不隐藏为所谓“原作真实值”。

以下 Wiki 链接可能在同一页面混排 SW1、SW2、Legacy 与 Saga，引用仅指先前核对的 **Legacy / SWL 专节**；不把网页标题本身当作版本证据。没有使用 Fanon 或修改版 APK 内容。

官方说明确认整军阵形与单兵操控、采金造兵、六种基本兵种、摧毁雕像、弓手瞄准、具有能力加成的皮肤，以及经典战役的六个附加关。[Google Play：Max Games Studios](https://play.google.com/store/apps/details?id=com.maxgames.stickwarlegacy&hl=en) 与 [App Store：Stick War: Legacy](https://apps.apple.com/us/app/stick-war-legacy/id1001780528) 为主要边界来源。

原项目的“所有手操伤害统一 +35%”不能作为 Legacy 的真实性依据；该数字容易与 Saga 的资料混淆。本版已取消这一统一加成，通过兵种专属动作、瞄准、格挡和位置控制表现手操收益。

本版手操回血使用战局共享的 `manualHealTimer`：只有战斗正在进行且接管了存活的己方单位时才累计；换人保留计时，交还指挥或暂停时停止累计。每累计 **5 秒**，为当时被接管的单位恢复 **10 HP**，不超过最大生命；即使当时生命已满，也会消耗这一轮 5 秒计时。社区 [Passive Heal and Cure](https://stick-war.fandom.com/wiki/Passive_Heal_and_Cure) 的 Legacy 内容是共享计时与 5 秒/10 HP 的参考；暂停、输入切换和存档恢复仍按本版实现与测试验证，不据此宣称所有版本的细节完全一致。

## 皮肤、关卡与画面范围

本版保留 Classic、Leaf、Ice、Lava、Savage、Vamp、Voltaic 七类，并按兵种分别保存解锁和装备。参考 [Skins/Stick War: Legacy](https://stick-war.fandom.com/wiki/Skins/Stick_War%3A_Legacy) 的被动与手操差异：例如 Leaf 的造价/训练、Ice 的减速、Lava 的反伤/灼烧、Vamp 的吸血。以下是当前代码采用的效果，具体幅度和组合属于网页规则；这是选定的七类内容，不是最新所有皮肤目录。

| 皮肤 | 本版准确效果与边界 |
| --- | --- |
| Classic | 无额外皮肤加成；巨人不开放地震 |
| Leaf | 招募金币为基础价的 90% 并向上取整，训练时间为 50%；只有被接管单位移动速度提高 15%，并非全军自动加速 |
| Ice | 命中使移动与冷却推进速度降至 70%，持续 2 秒；手操命中可造成 1 秒冻结（按眩晕处理），从触发时开始 3 秒内同一目标不能再次触发。蛮荒单位免疫冻结，但仍受到减速 |
| Lava | 反弹有攻击来源的实际直接伤害的 15%（箭雨、灼烧和连锁不触发反伤）；手操直接命中施加每秒 6 点、持续 3 秒的灼烧。目标只保存一份灼烧；新命中将持续时间刷新到 3 秒，但保留已有跳伤计时进度，只有原本未处于灼烧时才把跳伤计时清零，因此连续命中不会阻止每秒伤害，不叠加独立灼烧层数；反伤不递归触发皮肤效果 |
| Savage | 直接伤害提高 10%，免疫眩晕/冻结；不免疫普通减速 |
| Vamp | 对敌方单位的直接伤害按实际扣血量恢复 15% 生命，不超过最大生命；攻击雕像、连锁及灼烧不额外触发吸血 |
| Voltaic | 直接命中后，对距目标 85 以内最近另一名在场敌人造成实际伤害的 25%；连锁不再触发皮肤效果 |

皮肤所有权和装备按兵种保存；本版没有声称已采用社区表中每一种原作附加效果。例如额外毒免疫、各矿工特有生命加成和其他新增皮肤不在当前实现范围。

新 30 关全部是本项目重新编排的关卡数据。前 12 关借鉴经典战役的技术获得和遭遇节奏，后 18 关继续检验皮肤、阵地与混编策略。它们不是原作关卡数据文件，也不是逐帧还原的录像脚本。

经典解锁参考为：开始已有矿工与基础近战；第 1 关后获得弓手；第 3 关通关后开放剑士兵器升级；第 4 关后盾矛兵；第 6 关后法师；第 9 关后巨人。可分别查阅 [The War Begins](https://stick-war.fandom.com/wiki/The_War_Begins)、[Attack the Swordwrath](https://stick-war.fandom.com/wiki/Attack_the_Swordwrath)、[Attack the Spearton](https://stick-war.fandom.com/wiki/Attack_the_Spearton)、[Attack the Magikill](https://stick-war.fandom.com/wiki/Attack_the_Magikill) 与 [No Man’s Land](https://stick-war.fandom.com/wiki/No_Man%27s_Land_%28stage%29) 的 Legacy 说明。

身体、武器、盾牌、帽子和皮肤由原创 Canvas/SVG 绘制；动作采用共同姿势与时间。地图、角色音效、界面布局与键鼠映射是网页实现。天气只影响视觉，若某关有额外规则，必须在关前明确说明。

## 如何继续校准

1. 固定要比较的 Legacy 平台、版本、难度、兵器升级、皮肤与手操状态，记录这些条件。
2. 使用同一个场景重复观察：矿工一袋入账、单次招募、一次近战、箭矢飞行、格挡、投矛补给、召唤、地震。
3. 区分“按下按钮”“动作开始”“发生命中”“下一次允许行动”四个时间，不只凭动画快慢估计伤害周期。
4. 将新证据和调整理由写入这份记录，再改规则参数与相关说明；运行规则、回放、完整战役及双端操控检查。
5. 任何性能、手感或通关结果只能说明本版本在已测场景下的表现，不据此宣称与所有原作版本完全一致。

六种兵种练习使用独立战局和静止练习目标，成功后仅记练习完成；不发战役宝石/升级点、不消耗法术库存，不把练习中的临时装备或免费招募转移回主线。巨人练习的 Leaf 借用只在该战局有效。

家长可把这套方法缩小为三个问题：**我们改了什么？其他条件是否相同？看到的证据支持哪条解释？** 配套的三个进阶实验正是这个过程的可操作版本。
