# 余烬王国 v0.3.0

本版重构经典战役与单兵操控：六兵种具有独立动作，战场使用真实纵深与实际命中，双方依靠有限矿采掘和串行征兵建立军团。

- 重做 30 关，按科技解锁、装备特性和综合策略推进。
- 分离金币、战役升级点、宝石；七套皮肤按兵种解锁与装备。
- 电脑和触屏共用动作规则，战斗核心操作集中在一屏。
- 可选亲子半速、暂停下令与六兵种练习，辅助成绩单独记录。
- 旧成绩与战局归档，旧升级和道具返还资源价值，皮肤保留。
- 工坊保留 12 课并增加 3 个实验；提供 31 页教程、5 页活动卡和 15 个离线 HTML 作品。
